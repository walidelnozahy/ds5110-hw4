# HW4: Windows and Plans

DS 5110, Week 7. Window functions and query plans on MovieLens 100k. The tasks are in `HW04 brief.pdf`, and my answers are in `WRITEUP.md`.

## Run it

1. Copy the course `movielens.db` from Canvas into `data/` (it's git-ignored), or set `MOVIELENS_DB` to its path.
2. Run one task or all of them (needs Python 3.10+ and pandas):

```bash
python run.py t1
python run.py all
```

Results go to `output/`. Task 4 works on a copy of the database there, so the original is never changed.
